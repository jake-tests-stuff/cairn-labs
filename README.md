# Cairn Labs

Experimental build of Cairn. Try new things here on a phone before they go to the live app.

- Live app: https://jake-tests-stuff.github.io/Cairn/
- This preview: https://jake-tests-stuff.github.io/cairn-labs/

Both read and write the same Firestore data. Labs has its own app name, offline cache and local settings,
and push notifications are turned off here so you do not get doubles.
